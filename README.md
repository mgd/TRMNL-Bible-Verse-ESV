# TRMNL-Bible-Verse-ESV

## About
The Holy Bible English Standard Version (ESV) provides a *free* Api to request scritpure verses over. This allows for perfect integration via the [TRMNL E-Ink Display](https://usetrmnl.com). This allows users to request, display, and order  scripture verse(s) to the display.

## Obtaining ESV API KEY
At the time of writing users will need to manually request an API Key from ESV. While this is a non-commercial/non-profit use case, the [ESV Api Overview](https://api.esv.org) explicitly states [you may not sell share or publish your access key](https://api.esv.org/#:~:text=You%20may%20not%20sell%2C%20share%2C%20or%20publish%20your%20access%20key).

1. Create an account at [ESV account registration](https://www.esv.org/account/register/).  
2. Once an account has been created in step 1 [request a developer API Key](https://api.esv.org/account/create-application/).
  * Information here is provided as a template for registration and can be copy pasted in given it fits your intended use.
    * Application Name:	TRMNL-ESV-Plugin
    * Intended Use:	Personal Study
    * Use description:  This requested key will be used to display scripture verses on a personally owned TMRNL e-ink display (https://usetrmnl.com). A TMRNL community user created a plugin that allows other users to request and display scripture(s) on their TRMNL device in an easy to use pre-formatted way once they acquire their own personal API key.
    * Does your use fall within the API3 guidelines (below)?	yes (If its use meets the requirements listed below)  
3. Once an API Key has been distributed to you, save the plugin to your TRMNL and ener your API key into the API Key field, the rest of the fields for requesting information should be straight foward.
